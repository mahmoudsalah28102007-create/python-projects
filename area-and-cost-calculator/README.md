# Area and Cost Calculator

A simple Python program that asks for the length, width, and price per square meter, then calculates the total area and cost.

## How to run

1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python main.py
```

## Example

- Length: 5
- Width: 4
- Price per square meter: 10

Output:

```text
The total area is: 20.0
The total cost is: $200.0
```

## Concepts practiced

- `input()`
- Variables
- Converting values with `float()` and `str()`
- Multiplication
- Printing text and values
