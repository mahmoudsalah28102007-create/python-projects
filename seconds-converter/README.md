# Seconds Converter

A simple Python program that takes a number of seconds and converts it into hours, minutes, and remaining seconds.

## How to run

1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python main.py
```

## Example

Input:

```text
3671
```

Output:

```text
Hours: 1
Minutes: 1
Seconds: 11
```

## Concepts practiced

- `input()`
- Variables
- Converting input with `int()`
- Integer division with `//`
- Modulo with `%`
- Printing results
